# Trading Simulator

A React-based trading simulator that provides a realistic simulated market experience.

## Features

- Simulated live market prices
- Multiple assets
- Portfolio management
- Buy and sell functionality
- Price alerts
- Leaderboard
- Responsive UI

## Tech Stack

- React.js
- JavaScript
- Vite
- CSS
- React Hooks

## Getting Started

### Install dependencies

npm install

### Run the development server

npm run dev
